A 100-word monologue for a fantasy villain who is secretly just very tired — written by a deterministic program, judged head-to-head by an AI game-writer judge. The tiredness lives in the rhythm, the pauses and the small deflections, never in a plain statement; the villain keeps a scheme (the eclipse, Thursday), a history (thirty years, Karth's crown in the vault) and a sting in the last line.

## Run it

```sh
node main.ts
```
